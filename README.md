# Vellum (дизайн-прототип)

Android, Kotlin, Jetpack Compose. Сейчас это только интерфейс: данные демонстрационные,
VPN-ядро (sing-box) и парсер каналов будут на следующем шаге.

## Как открыть
1. Установить Android Studio (бесплатно).
2. File → Open → выбрать папку `Vellum`.
3. Дождаться синхронизации Gradle. Если Android Studio спросит про wrapper, нажать «Use gradle wrapper» или выполнить `gradle wrapper`.
4. Run ▶ на телефон или эмулятор (minSdk 26, Android 8.0+).

## Что внутри
- `ui/Theme.kt`: шрифт Manrope (все веса), палитра, типографская шкала.
- `ui/Glass.kt`: стеклянная панель (`glass`), пружинное нажатие (`pressable`), `GlassCard`.
- `ui/Aurora.kt`: фон с плавно двигающимися цветовыми пятнами. Фиолетовый/розовый — выключено, бирюзовый — подключено.
- `ui/HomeScreen.kt`: главный экран, большая кнопка питания с пульсом и вращением при подключении, статистика.
- `ui/ServersScreen.kt`: список серверов с пингом и кнопкой обновления.
- `ui/SettingsScreen.kt`: каналы-источники, интервал обновления, переключатели.
- `ui/GlassNav.kt`: нижняя навигация, активный пункт раскрывается с подписью.
- `AppState.kt`: демо-состояние. Его заменим на реальный VPN и парсер.
